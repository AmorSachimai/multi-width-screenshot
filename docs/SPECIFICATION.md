# 機能仕様書 (SPECIFICATION)

## 概要
「Multi-Width Screenshot Capture」は、ウェブページを複数の指定した横幅で自動撮影し、一括で ZIP 保存する Chrome 拡張機能です。レスポンシブデザインの確認作業を効率化することを目的としています。

## 主要機能

### 1. マルチ幅キャプチャ
- ユーザーが指定した複数の横幅（px）に対して、連続してスクリーンショットを撮影します。
- デフォルトの解像度セット（375px, 768px, 1280px, 1920px）を提供し、ユーザーが自由に追加・削除・編集できます。

### 2. フルページキャプチャ
- Chrome DevTools Protocol (CDP) を使用し、スクロールが必要な長いページも一枚の画像として高品質にキャプチャします。
- レイアウト崩れを防ぐため、撮影前に「プリスクロール（遅延読み込みのトリガー）」と「ウィンドウのリサイズ」を自動で行います。

### 3. ZIP アーカイブ保存
- 撮影したすべての画像を、ページタイトルに基づいたファイル名の ZIP アーカイブとして一括ダウンロードします。
- 各画像は `{ページタイトル}_{横幅}px.{拡張子}` の形式で命名されます。

### 4. 設定の永続化
- ユーザーがカスタマイズしたターゲット幅のリスト、画像フォーマット（JPEG/PNG）、品質設定、スクロール遅延などは `chrome.storage` に保存され、次回起動時も維持されます。

## ユーザーインターフェース (UI)

### ポップアップ画面
- **解像度リスト**: チェックボックス形式で撮影対象を選択。
- **解像度追加**: 新しい横幅を入力して追加。
- **撮影ボタン**: キャプチャフローを開始。
- **進捗表示**: 現在の撮影対象、全体の進捗率、ZIP圧縮の進捗をプログレスバーで表示。

## 技術的制限・仕様
- **ブラウザ**: Google Chrome (Manifest V3)
- **権限**: `debugger`（CDP操作用）、`storage`（設定保存用）、`activeTab`（現在ページの操作用）、`downloads`（ファイル保存用）。
- **画像形式**: JPEG (デフォルト) または PNG。
- **最大幅**: 4000px 程度まで（ハードウェア/OSの制限に依存）。
