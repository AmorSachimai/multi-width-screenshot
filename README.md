# Multi-Width Screenshot Capture

> [!NOTE]
> このアプリケーションは AI (Antigravity) によって一貫して生成、管理されています。
> アーキテクチャの設計、型安全性の確保、および UI 実装のすべてが AI とのペアプログラミングによって構築されています。

ウェブリスページを複数の指定した横幅で自動撮影し、一括で ZIP 保存する Chrome 拡張機能です。
レスポンシブデザインの確認や、複数のデバイスサイズでの表示確認を効率化します。

## 主な機能

- **マルチ幅キャプチャ**: 複数の解像度（横幅）を一度に指定して撮影。
- **フルページ撮影**: Chrome DevTools Protocol (CDP) を使用し、スクロールを伴うページ全体の高品質なキャプチャ。
- **ZIP 保存**: 撮影した画像をプロジェクト名やタイムスタンプに基づき、一括で ZIP 圧縮してダウンロード。
- **プリセット管理**: よく使う画面幅を保存・編集可能。
- **プレミアムな UI**: モダンで動的なユーザーインターフェース。

## 技術スタック

- **Frontend**: React 19, Tailwind CSS (Vite 8)
- **Language**: TypeScript (厳格な型安全性を維持)
- **Tooling**:
  - **Package Manager**: pnpm
  - **Linter/Formatter**: Biome
- **Architecture**: クリーンアーキテクチャ指向のレイヤー構造
- **Runtime Validation**: Zod による外部データ検証

## 開発環境のセットアップ

### プロジェクトのインストール

```bash
pnpm install
```

### 開発用ビルド（Vite）

```bash
pnpm dev
```

### 拡張機能用ビルド

```bash
pnpm build
```

ビルド後、`dist` ディレクトリが生成されます。Chrome の拡張機能管理画面 (`chrome://extensions/`) から「パッケージ化されていない拡張機能を読み込む」を選択し、`dist` フォルダを指定してください。

## 使い方

1. 拡張機能アイコンをクリックしてポップアップを開きます。
2. 撮影したい解像度（横幅）を選択または追加します。
3. "Start Capture Flow" ボタンをクリックします。
4. 自動でウィンドウサイズが変更され、全画面キャプチャが開始されます。
5. 完了すると、ZIP ファイルが自動的にダウンロードされます。
